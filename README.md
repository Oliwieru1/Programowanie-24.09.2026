Generator haseł – WinFormsApp1
Opis projektu

Aplikacja desktopowa napisana w języku C# z wykorzystaniem technologii Windows Forms. Program umożliwia generowanie losowych haseł oraz wyświetlanie danych pracownika, takich jak imię, nazwisko i stanowisko.

Funkcjonalności
Generowanie losowych haseł o określonej długości.
Możliwość uwzględnienia małych liter.
Możliwość uwzględnienia cyfr.
Możliwość uwzględnienia znaków specjalnych.
Wyświetlanie wygenerowanego hasła w oknie komunikatu.
Wyświetlanie danych pracownika wraz z wygenerowanym hasłem.
Technologie
Język programowania: C#
Platforma: .NET
Interfejs graficzny: Windows Forms
Środowisko programistyczne: Visual Studio
Uruchomienie projektu
Pobierz lub sklonuj repozytorium.
Otwórz plik rozwiązania .sln w programie Visual Studio.
Przywróć wymagane zależności, jeśli są potrzebne.
Uruchom aplikację za pomocą przycisku Start lub klawisza F5.
Instrukcja obsługi
Wprowadź imię i nazwisko pracownika.
Wpisz stanowisko pracownika.
Podaj liczbę znaków, z których ma składać się hasło.
Zaznacz odpowiednie opcje dotyczące znaków używanych do generowania hasła.
Kliknij przycisk generowania hasła.
Aby wyświetlić dane pracownika wraz z hasłem, kliknij odpowiedni przycisk.
Cel projektu

Celem projektu jest nauka programowania w języku C#, obsługi zdarzeń w Windows Forms, korzystania z kontrolek interfejsu graficznego oraz generowania losowych ciągów znaków.
